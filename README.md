# Student Grade Project - Software Maintenance Task

This project demonstrates software maintenance activities using Git and JUnit.

## 🛠 Maintenance Types Applied:
1. **Adaptive Maintenance:** Integrated `junit-3.8.1.jar` to support legacy test code.
2. **Perfective Maintenance:** Re-implemented the test suite using **JUnit 5** for better performance and modern standards.

## 🌿 Branches:
* `master`: The main branch with the final merged code.
* `Re-Implement_Junit5`: Development branch used for the migration task.

## 🚀 Tools:
* Java, JUnit 5, Git, and NetBeans.
